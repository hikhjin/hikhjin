## 💡 Core Competencies

**결제 데이터 정합성**
토스페이먼츠 연동 중 발생한 결제 타임아웃으로 인한 자사몰-PG사 간 데이터 불일치 문제를 배치 기반 정합성 검증 로직으로 해결, 고객 이중 청구 리스크 자동화 처리 체계 구축

**대용량 배치 최적화**
JPA IDENTITY 전략의 Bulk Insert 미작동과 Bigtable 단건 I/O 반복으로 인한 배치 지연을 JdbcTemplate 직접 구현 및 Chunk 기반 조회로 전환, 3만 건 기준 처리 시간 45분 → 5분 단축

**동시성 제어 및 인증 시스템 안정성 확보**
오토스케일링 환경의 스케줄러 중복 실행과 RTR 인증 시스템의 Race Condition을 ShedLock 기반 Redis 분산 락·Grace Period 설계로 해결, 데이터 정합성과 사용자 세션 안정성 동시 확보
